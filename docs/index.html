01 the runtime · grand

A boundary, not a chatbot.

An LLM orchestrator routes tasks. Per-task agents run inside isolated sandboxes — base · browser · ffmpeg · netsec · runtimectl. The Guard authorises every command, every domain, every IP — before it touches a server.
